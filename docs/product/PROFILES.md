# Experience profiles (D0 documentation)

Default for D0: **Balanced**.

Automatic hardware detection is **out of scope** for D0.

| Concern | Performance | Balanced | Lightweight |
|---------|-------------|----------|-------------|
| Animations | Full | Moderate | Minimal / off |
| Desktop effects | Full | Standard | Reduced |
| Background services | Full set | Default | Trimmed |
| Memory target | Higher | Medium | Lower |
| Visual complexity | Rich | Default Tuwaiq look | Simplified |

Hooks will later map to Plasma config, systemd user units, and Platform
settings. No runtime switcher is required for D0 acceptance.
